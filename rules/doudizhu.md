# 斗地主 · 规则 1.0.0
三人经典叫分斗地主：玩家对阵两个独立模型席位，单局结算，可再来一局。

## 发牌与叫分
- 一副54张牌，3 < 4 < … < K < A < 2 < 小王 < 大王；花色不分大小，无赖子。
- 每人17张，3张底牌暂时保密。随机首叫，按玩家→对手1→对手2的座次轮流叫分。
- 每人只叫一次：不叫（0），或高于当前最高分的1/2/3分。叫3分立即结束叫分；否则三人叫完取最高分者为地主。全不叫则进入重新发牌页，由玩家点“重新发牌”，首叫顺延一位。
- 地主拿到并公开3张底牌，先出牌。另两人为农民；农民共享胜负，但互相不知道手牌。

## 出牌
- 行动格式：叫分 `{kind:"bid",score:0|1|2|3}`；出牌 `{kind:"play",cards:["3","3"]}`；不出 `{kind:"pass"}`。
- 单张、对子、三张、三带一、三带一对、顺子（至少5张）、连对（至少3对）、飞机（至少2组三张，可不带牌、带等量单牌或对子）、四带二单牌、四带两对、炸弹、王炸。
- 顺子／连对／飞机主体不能包含2或王。飞机单翼必须点数各异，对翼必须是不同点数的对子；翅膀不能与主体同点。大小王可分别作单翼。四带二单牌允许两张同点；四带两对必须是不同点数的对子。三带牌不能与主体同点。
- 通常只可用相同牌型、相同张数且主体更大的牌压过上一手；炸弹压普通牌，王炸压一切，炸弹之间按点数比较。四带二不是炸弹。
- 可在别人的有效出牌后不出；连续两家不出后，上次出牌者重新领出任意合法牌型，领出不能不出。任一人出完即结算；地主出完地主胜，任一农民出完两农民共同胜。

## 单局计分
- 基础分为地主叫分；每个实际打出的炸弹或王炸将倍率乘2。
- 地主胜且两农民均未出过牌为春天；农民胜且地主只出过一次牌为反春天；再乘2。
- 记单位分为基础分×倍率：地主胜时地主+2单位、两农民各-1单位；地主负则相反。三方总分恒为0。不设货币、持久余额或跨局排行榜。
- 结算公开剩余手牌。整局公开出牌、叫分与底牌可查看，未结束前对手手牌、随机种子、牌序和随机状态不公开。

这是本插件的明确变体；不同平台的飞机翅膀等细节可能不同。三人角色与轮次结构参照 [RLCard 的斗地主说明](https://rlcard.org/games.html#dou-dizhu)；本实现独立编写，不采用其自动指定地主规则。
