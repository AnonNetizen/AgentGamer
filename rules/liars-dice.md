# 双人吹牛骰 · 规则 1.0.0

玩家与 Agent 五局三胜，先赢三局结束。每局双方都重新使用五颗六面骰，不扣骰。首局随机首叫，之后由上一局败方首叫。人类点击“下一局”推进；整场后可以再来一场或返回大厅。

每人只能看到自己的有效骰面。五颗点数互不相同是散骰，系统公开该次弃用骰面并自动重摇，直到得到有效结果。最终有效骰面在开盅前对另一方隐藏。

叫点“数量个点数”表示全场至少有这么多个该点数，数量上限14。普通模式首叫至少3个，斋首叫至少2个。普通模式1可代替任意2～6点；斋模式1只算1，其他点数只算本身。叫1自动为斋。

加叫按数量优先：数量增加可以降低点数；数量相同必须提高点数。改叫斋也必须提高数量或在同数量时提高点数，不能仅改变模式而重复同一叫点。斋后只能继续斋，或叫飞恢复普通模式；叫飞至少是前次数量的两倍，点数只能2～6。

计数分别计算双方，然后相加：

| 骰型 | 有效数量 |
| --- | --- |
| 五颗实际都为所叫点数（全围） | 7，普通和斋均生效 |
| 普通模式下五颗均为所叫点数或1，且含替代用的1（围骰） | 6 |
| 其他普通骰型 | 所叫点数的实际颗数加上1的颗数 |
| 其他斋骰型 | 所叫点数的实际颗数 |

例如五个1，普通叫6算6个6；叫1斋算7个1；叫6斋算0个6。双方都为五个6时，叫14个6斋可以成立。

轮到自己且已有对方叫点时，可以选择开盅质疑。双方揭示有效骰面：总有效数量大于或等于叫点数量，叫点方赢本局；否则质疑方赢。没有平局。结算页保留双方骰面与计数依据，下一局才重新掷骰。

不启用连开、劈、反劈、投降、惩罚倍数或扣骰。聊天不改变叫点或游戏结果。

规则参考：[萌娘百科“吹牛”](https://zh.moegirl.org.cn/zh-hans/%E5%90%B9%E7%89%9B)。本平台固定采用上述双人五局三胜规则，加叫顺序、全围在斋时计7等边界已在本地规则中明确。

## Agent 行动

`bid` 包含 `quantity`、`face`、`mode`（`wild` 或 `straight`）；`challenge` 无额外参数。观察 `actions` 中的 `bid.options` 按点数及模式给出 `minimum`、`maximum`，避免枚举所有数量。必须使用当前 `matchId`、`expectedRevision` 与唯一 `requestId`。

当前局面只包含本方骰面和公开叫点。已结束局的 Agent 历史压缩为结果摘要；人类记录保留双方公开骰面和叫点过程。没有合法行动时结束模型回合，等待人类推进或新聊天。
